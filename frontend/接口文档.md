# 实况联动助手 - 后端接口文档

## 1. 获取首页统计数据

- **接口地址**：`GET /api/stats`
- **描述**：获取当前服务总人数、已完成任务人数、进行中任务人数
- **请求参数**：无
- **响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "total": 128,
    "finished": 86,
    "ongoing": 42
  }
}
```

---

## 2. 获取用户任务进度列表

- **接口地址**：`GET /api/user-tasks`
- **描述**：获取用户任务进度表格数据，支持关键词搜索和分页
- **请求参数**：

| 参数名      | 类型   | 必填 | 说明           |
| ----------- | ------ | ---- | -------------- |
| page        | int    | 否   | 页码，默认1    |
| pageSize    | int    | 否   | 每页数量，默认10|
| keyword     | string | 否   | 搜索关键词（可匹配昵称、ID、账号、微信昵称等）|

- **响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "total": 128,
    "list": [
      {
        "index": 1,
        "date": "2023-07-04",
        "gameName": "银河战神",
        "gameId": "66889900",
        "loginAccount": "13812345678",
        "wechatName": "踢球的小黑",
        "days": "15/15天",
        "status": "已完成"
      },
      {
        "index": 2,
        "date": "2023-07-05",
        "gameName": "足球小将",
        "gameId": "88776655",
        "loginAccount": "football@qq.com",
        "wechatName": "快乐玩足球",
        "days": "14/15天",
        "status": "进行中"
      }
      // ...更多数据
    ]
  }
}
```

## 3. 获取最新公告

- **接口地址**：`GET /api/notice/latest`
- **描述**：获取首页公告栏的最新公告内容
- **请求参数**：无
- **响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "title": "【最新】端游联动活动开启，连续登录15天可获得手游专属奖励！",
    "content": "活动时间：2023年7月4日 - 2023年8月4日"
  }
}
```

## 4. 联系我们（可选）

- **接口地址**：`POST /api/contact`
- **描述**：用户点击“联系我们”后提交表单（如有）
- **请求参数**：

| 参数名    | 类型   | 必填 | 说明         |
| --------- | ------ | ---- | ------------ |
| name      | string | 是   | 用户姓名     |
| email     | string | 是   | 用户邮箱     |
| message   | string | 是   | 咨询内容     |

- **响应示例**：

```json
{
  "code": 0,
  "msg": "提交成功"
}
```

---

## 5. 根据手游ID查询用户任务信息

- **接口地址**：`GET /api/user-tasks/{gameId}`
- **描述**：根据手游ID查询单个用户的任务进度信息
- **请求参数**：

| 参数名   | 类型   | 必填 | 说明     |
| -------- | ------ | ---- | -------- |
| gameId   | string | 是   | 手游ID   |

- **请求示例**：

```
GET /api/user-tasks/66889900
```

- **响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "index": 1,
    "date": "2023-07-04",
    "gameName": "银河战神",
    "gameId": "66889900",
    "loginAccount": "13812345678",
    "wechatName": "踢球的小黑",
    "days": "15/15天",
    "status": "已完成"
  }
}
```

---

## 说明

- 所有接口建议统一返回结构：`code`（状态码），`msg`（提示信息），`data`（数据体）。
- 列表接口建议支持分页和关键词模糊搜索，便于前端扩展。
- 如有权限控制、登录等需求，可补充 token 校验等字段。
